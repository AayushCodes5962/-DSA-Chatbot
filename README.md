Code Mentor AI is an AI-powered coding instructor that uses the Google Gemini API to help users understand programming and Data Structures and Algorithms concepts through simple and beginner-friendly explanations.

## Features

* AI-powered coding instructor
* Data Structures and Algorithms explanations
* Beginner-friendly explanations
* Coding problem assistance
* Code debugging support
* Dark-themed user interface
* Responsive design
* Google Gemini API integration

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Gemini API
* Font Awesome

## Project Overview

The application provides an interactive interface where users can enter programming and DSA-related questions and receive AI-generated explanations.

Example questions:

* What is recursion?
* Explain binary search.
* What is a linked list?
* Explain dynamic programming.
* How does BFS work?
* What is the time complexity of this algorithm?
